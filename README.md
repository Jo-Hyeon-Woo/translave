# Translave

PDF 원본을 왼쪽에서 읽고 현재 페이지의 번역을 오른쪽에서 확인하는 데스크톱 앱입니다.

**PDF 전체 자동 번역과 SQLite 로컬 저장을 구현했습니다.** 토큰 예산에 맞춰 여러 페이지를 묶어 요청하고, 현재 페이지가 포함된 묶음을 우선 처리합니다. 결과는 페이지별로 저장합니다. 재실행 후 같은 PDF를 열면 번역과 읽던 위치를 복원합니다. 자동 테스트는 가짜 API로 검증했으며 실제 번역 품질과 설치 패키지는 별도 검증이 필요합니다. 저장된 번역도 키도 없는 샘플에는 미리 작성한 예시를 표시합니다.

## 실행

macOS와 Node.js 24 이상이 필요합니다. 이 프로젝트 폴더에서 실행하세요.

```sh
npm ci
npm run dev
```

설치 시 Electron 실행 파일을 다운로드하므로 처음에는 인터넷이 필요합니다. 이후 PDF 표시에는 인터넷이나 API 키가 필요하지 않습니다.

개발 서버 없이 빌드된 앱을 실행하려면:

```sh
npm run build
npm start
```

이 명령은 Electron으로 빌드 결과를 실행합니다. 독립 설치용 `.app`/DMG 배포는 M4 범위입니다.

## 사용

- 상단 오른쪽 **파일** 버튼 또는 **⌘O**로 문서 목록을 엽니다. 목록 오른쪽 위 **+**로 PDF를 추가하고 각 행의 **열기**를 눌러 읽습니다. 추가만 하면 현재 뷰어는 그대로 유지됩니다. 첫 화면의 **샘플 문서로 둘러보기**는 샘플을 바로 엽니다.
- 목록은 최근 열람 순이며 썸네일·번역 상태·완료 페이지 수·진행 게이지를 표시합니다. 중단된 문서의 새로고침 아이콘 **번역 재개**를 누르면 해당 PDF를 열고 이어 번역합니다. 키가 없으면 설정창이 열립니다.
- 목록은 앱을 닫아도 유지됩니다. 원본을 이동했거나 이전 버전에서 열었던 PDF라면 처음 다시 열 때 같은 원본을 선택해 주세요.
- PDF 카드 좌상단 화살표·페이지 번호·키보드 좌우 화살표로 페이지를 이동합니다.
- `+` / `−`로 확대·축소하고 **너비에 맞추기**로 원래 배율에 돌아옵니다.
- PDF 본문을 마우스로 드래그해 선택·복사할 수 있습니다.
- 오른쪽 **추출 텍스트** 탭에서 로컬에서 추출한 원문을 확인합니다. 이 텍스트는 API에 보내지 않습니다.
- 가운데 구분선을 드래그해 패널 너비를 조절합니다. 구분선에 키보드 초점을 둔 뒤 좌우 화살표를 써도 됩니다.

샘플은 일반 글, 두 단 문서, 표·수식, 이미지 전용 페이지의 4페이지로 구성됩니다. 직접 제작한 테스트 자료이며 `npm run fixtures`로 재생성할 수 있습니다.

## Gemini 무료 API 연결

1. [Google AI Studio](https://aistudio.google.com/apikey)에서 API 키를 발급하고 프로젝트가 **Free 등급**인지 확인합니다. 결제 연결은 필요하지 않습니다. 계정·지역에 따라 사용 가능 여부와 한도가 다릅니다.
2. 앱 오른쪽 위 **설정**에서 API 키를 입력하고 Free 등급 확인란을 선택합니다.
3. **키 적용하고 번역 시작** → **계속 읽기**를 누릅니다. 파일 추가만 해도 컬러 페이지 이미지를 백그라운드에서 자동 번역하며, 읽는 문서의 현재 페이지가 우선합니다. 샘플도 키 연결 후에는 API를 사용합니다.
4. **설정 → 묶음 번역 예산**에서 입력 예산(기본 16,000)과 출력 상한(기본 16,384)을 변경할 수 있습니다. 로컬 DB에 저장해 다음 실행에도 유지하며 예산 변경은 완료 페이지를 재호출하지 않습니다. 저장된 구 기본값 12,000 / 8,192는 한 번 갱신하고 다른 사용자 지정 값은 보존합니다.
5. 파일 목록에서 전체 진행률을 확인하고 번역 패널 **⋯**에서 **다시 번역**, **실패한 페이지 재시도**, **자동 번역 일시정지/재개**를 사용할 수 있습니다. 상단 오른쪽 **파일** 버튼으로 목록을 엽니다. 파일 이름은 텍스트로 표시하고 페이지·확대 컨트롤은 PDF 카드 상단에 있습니다. **연결 대기**를 눌러 기존 키 설정을 열 수도 있습니다. Gemini 초록 점은 키 적용 상태이며 실제 인증 성공을 보증하지 않습니다. 이미지/스캔 페이지도 번역합니다. **설정 → 번역 이미지 설정**에서 해상도·형식·품질·판독 수준·요청 용량을 조절할 수 있습니다.

모델은 `gemini-3.5-flash-lite`로 고정했습니다. 앱은 Google 프로젝트의 요금 등급을 조회하거나 무료 사용을 강제할 수 없습니다. **유료 프로젝트 키를 입력하면 과금될 수 있으므로 Free 등급의 키를 사용하세요.** 할당량은 [AI Studio](https://aistudio.google.com/)에서 확인합니다. 한도 초과 시 최대 2회 대기·재시도하고, 계속 실패하면 해당 문서를 중단하고 다른 문서를 처리합니다. 한도가 회복된 뒤 재개하세요. 다른 유료 모델로 자동 전환하지 않습니다. [공식 가격표](https://ai.google.dev/gemini-api/docs/pricing#gemini-3.5-flash-lite)

번역할 페이지의 컬러 이미지와 페이지/영역 식별자·요청 지시문을 Google에 전송합니다. 추출 텍스트는 원문 탭과 로컬 출력량 추정에만 사용합니다. 무료 서비스의 입력과 응답은 제품 개선에 사용될 수 있습니다. 키는 적용 직후 입력창에서 지우고 메인 프로세스 메모리에만 보관합니다. 키·본문·이미지/base64·번역문을 앱 로그에 기록하지 않습니다. 창을 닫거나 키를 삭제하면 키는 지워지지만 저장된 번역은 유지됩니다.

인증 오류는 키·API 사용 권한·지역을 확인한 뒤 새 키를 적용하세요. 네트워크/서버 오류는 잠시 후 재시도할 수 있습니다. 긴 페이지는 분할하며 일부 구간 실패·빈 응답·출력 잘림을 완료로 처리하지 않습니다.

## 로컬 DB

**설정 → 번역 DB 저장 폴더 열기**로 위치를 확인할 수 있습니다. 파일은 Electron 앱 데이터 폴더의 `translations/translations.sqlite`이며 쓰는 동안 `-wal`/`-shm` 파일이 함께 있을 수 있습니다.

문서 해시·이름·원본 경로·첫 페이지 썸네일·최근 열람 순서·읽던 페이지·일시정지 상태와 페이지별 Markdown 번역·시각 설명·읽기/판독 메타데이터·결과 상태와 이미지 설정·묶음 예산을 저장합니다. API 키·PDF 파일 자체·추출 원문은 저장하지 않습니다. DB는 암호화하지 않은 로컬 파일입니다. 백업할 때는 앱을 완전히 종료한 뒤 저장 폴더를 복사하세요. 모델·이미지 입력 방식·번역 지침/응답 스키마·이미지 설정이 바뀌면 해당 버전의 완료 결과만 재사용합니다. 기존 텍스트 번역과 문서는 삭제하지 않으며 이미지 번역 완료로 오인하지 않습니다.

## 검증

작업 중에는 변경 영향에 맞는 검사를 선택하고, 최종 통합·배포 전에는 전체 검사를 수행합니다. 선택 실행은 전체 회귀 통과를 의미하지 않습니다.

```sh
npm run typecheck
npm test
npm run test:e2e
npm run format:check
```

```sh
npm run test:select -- --unit --category pdf
npm run test:select -- --e2e --category chat
npm run test:select -- --category translation,queue
npm run test:select -- --files src/main/chatgpt/batching.ts --list
```

`--list`를 빼면 실행하며, 종류 생략 시 단위+Electron을 검사합니다. 현재 폴더는 Git 저장소가 아니므로 변경 파일을 `--files`로 지정합니다. 공통 기반/미매핑 경로는 보수적으로 확대하고 문서 전용 변경은 자동 미실행을 명시합니다. 전체 명령은 그대로 유지합니다. 상세 범주·선택 정책·중복 정리 근거는 [테스트 안내](tests/README.md)에 있습니다.

통합 테스트는 실제 Electron 창을 띄우므로 macOS의 GUI 세션에서 실행하세요. 테스트는 임시 프로필을 사용하며 실제 LLM을 호출하지 않습니다. 테스트 캡처는 `test-results/`에 저장됩니다.

## 지원 범위와 제약

- 초기 파일 상한 150MB, 한 페이지씩 표시, 25–300% 확대/축소.
- 텍스트 추출이 없는 스캔도 Gemini가 이미지를 읽어 번역합니다. 외부 OCR은 없으며 판독 불가 영역은 별도로 표시합니다. 모든 영역이 판독 불가인 결과는 완료하지 않습니다.
- 암호화·손상 PDF는 안내를 표시하고 기존 문서를 유지합니다.
- 일반 수평 텍스트와 샘플의 2단 편집을 처리합니다. 복잡한 레이아웃·표 구조·수식·회전 텍스트는 추출 순서가 정확하지 않을 수 있습니다.
- 완료 번역과 읽던 위치는 SQLite에 보관합니다. 앱 재실행 시 같은 PDF를 다시 선택하면 복원되며 저장된 번역은 키 없이 읽을 수 있습니다.
- 새 번역을 계속하려면 API 키를 다시 입력하세요. 일시정지는 진행 중 페이지의 취소도 시도하므로 재개할 때 해당 페이지를 다시 요청할 수 있습니다.
- 페이지를 바꾸면 진행 중 번역은 저장하고 다음 순서부터 새 페이지를 우선합니다. 다른 미완료 문서를 열면 진행 중 요청이 끝난 뒤 우선순위를 바꿉니다. 이전 문서의 남은 작업도 큐에 보존됩니다.

## 구조와 다음 단계

- `src/main`: 네이티브 파일 선택, 로컬 파일 읽기, 파일 해시, 제한된 IPC, Gemini 호출, 전체 문서 작업 큐, SQLite 저장.
- `src/preload`: 렌더러에 필요한 작업만 노출하는 브리지.
- `src/renderer`: PDF.js 렌더링·텍스트 선택·추출, 읽기 화면, 키 설정, 번역 패널.
- `resources/reading-notes.pdf`: 직접 제작한 샘플 PDF.
- `SPEC.md`: 제품 동작과 완료 기준.
- `PLAN.md`: 마일스톤과 검증 기록. 다음 구현은 **M4 — 로컬 앱 패키징**이며 실제 API 품질 검증도 남아 있습니다.
- `AGENTS.md`: Codex 작업 규칙과 개발 명령.

## 이미지 묶음 번역 동작

필요한 PDF 페이지만 뷰어와 독립적으로 흰 배경·원본 색·회전을 적용해 렌더링합니다. 기본값은 144 DPI, JPEG 품질 90%, 판독 수준 high, 요청 전체 16 MiB입니다. 고해상도 이미지를 전체 문서에 대해 미리 만들거나 파일로 저장하지 않습니다.

입력 이미지의 보수적인 토큰 추정·지시문/식별자 비용·예상 번역/시각 설명 출력량·실제 JSON 전송 바이트로 페이지 묶음을 결정합니다. 입력 예산 범위는 이미지 입력을 위해 4,096–32,000, 출력 범위는 2,048–16,384입니다. 단독 페이지가 넘칠 때 영역을 분할하고, page/part와 읽기 순서로 모든 조각을 합쳐 페이지 단위로 저장합니다. 잘림·누락·중복·빈 text·잘못된 JSON은 최대 두 단계 축소 재시도하며 부분 성공은 완료하지 않습니다.

번역 본문은 안전한 Markdown으로 표시하고, 시각 설명/읽기 정보·판독 문제는 아래 접기 영역에 분리합니다. 원시 HTML·외부 이미지·링크 탐색은 차단합니다. blank/visual_only는 규칙에 맞으면 완료, unreadable은 확인 필요 오류로 남깁니다. ⋯ 메뉴에 다시 번역과 자동 번역 제어가 있습니다.

토큰 수는 정확한 사용량이 아닌 계획값이며 실제 Gemini 3.5 Flash-Lite의 토큰·지연·품질은 별도 검증이 필요합니다. JSON 검증은 의미상 번역 누락이나 판독 정확성까지 보장하지 않습니다. 추정 근거와 설정/상한은 SPEC.md, 가짜 API 및 화면 검증은 PLAN.md에 기록합니다.
